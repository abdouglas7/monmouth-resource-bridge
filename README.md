# Monmouth Resource Bridge

## Project Overview
Monmouth Resource Bridge is a community resource platform designed to help individuals and families discover free and low-cost services, public benefits, emergency assistance, healthcare, housing, and workforce programs across Monmouth County, New Jersey, with an architecture designed to expand statewide.
